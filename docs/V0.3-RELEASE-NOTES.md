# Wolf Den v0.3.0 — Release notes (prepared, not yet published)

Wolf Den grows from a multi-project dashboard into a configurable, keyboard-driven development cockpit. The Den stays local-first and deliberately small: a clear view of your projects, safe shortcuts back to work, and editable Wolf Den settings without touching your Git repositories.

## Highlights

- **Project radar and redesigned workbench:** clearer project selection and factual Git signals across registered projects; selected-project details distinguish local Git, GitHub activity and Next Action.
- **More useful pull requests:** compact open/draft rows, expandable selected-PR details, and context-sensitive keyboard help.
- **Wolfy Dark and color customization:** semantic theme tokens, an initial built-in preset and 18 color overrides with live preview, Save, Cancel and appearance-only Reset.
- **Full-width Settings:** keyboard-accessible Appearance, Projects and General sections; configurable terminal preference.
- **Project Manager:** add, edit and remove registrations inside Wolf Den. Stable project IDs, useful validation, clear removal confirmation, and empty-state support. “Remove from Den” removes only the registration.
- **Safe, explicit configuration saves:** changes are staged in a shared draft before a validated, atomic, revision-conflict-aware registry write. External edits and failed writes receive recovery guidance.
- **Manual Next Action editing:** set, change or clear an action through Settings → Projects → Edit. The cockpit displays the registry value, without inventing a task from PRs or commits.

## Compatibility and boundaries

- Existing version-1 `~/.config/wolf-den/projects.json` registries remain supported; no migration is required.
- Local Git and GitHub providers remain read-only. Wolf Den may update only **its own registry** when you explicitly Save.
- No automatic discovery, repository mutation, background service, database or agent orchestration.
- The planned direct cockpit `n` editor ([#28](https://github.com/VesaMalaska/wolf-den/issues/28)) is deferred beyond v0.3. A future producer-independent Project Status Contract is separately planned, **not part of this release**.

## Requirements and upgrade

Linux-first; Node.js **26.4.0 or later** with experimental FFI support; pnpm **11.22.0**; Git, plus optional authenticated GitHub CLI (`gh`). From your checkout, install with `pnpm install --frozen-lockfile`, build with `pnpm build`, and launch with `pnpm start`. Keep a personal backup of your registry before changing settings.

## Known limitations and release gate

GitHub refresh is manual, counts at the 1,000-result limit are unavailable, PR opening needs fresh GitHub data, and the next action is registry-owned. Narrow views clip long lines; use a wider window to read full content. External process launch success does not verify that a graphical window opened or inherited the intended directory. System terminal behavior depends on `xdg-terminal-exec` availability and its desktop entry; the fixed fallback is used only when that executable is missing.

**Release blocker:** Issue #13 explicitly requires human review of real Kitty wide/compact layouts and external desktop behavior. That acceptance is pending. No reproducible implementation defect was found by the automated and PTY checks above. After the owner completes the checklist and resolves any findings, v0.2 can receive final human acceptance; do not tag or release before explicit approval.
